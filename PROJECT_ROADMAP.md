# Development Principles

For every phase:

✓ Plan before coding.

✓ Build reusable components.

✓ Test before moving forward.

✓ Keep architecture clean.

✓ Never break existing functionality.

✓ Update documentation when features change.

---

# Success Criteria

Version 1 is considered complete when:

- Chat Mode is stable.
- English and Nepali conversations work.
- MongoDB stores conversations.
- Ollama integration is complete.
- Desktop application is polished.
- Documentation is up to date.

Only after achieving these goals should Agent Mode development begin.
